# 活力红金风主题指南（配色已由粉白升级为品牌红金）

> ⚠️ 本主题为原创设计：品牌红 + 金黄 + 白底，快餐活力调性。
> **不使用**任何品牌官方 Logo、商标、门店照片或受版权保护的素材。
> 主题标识仍为 `cute`（`--theme cute`），以保持脚本兼容。

## 视觉元素（文本/界面通用）

- 主色：品牌红 `#DB0007`
- 辅助色：金黄 `#FFBC0D`
- 背景：纯白 `#FFFFFF`
- 正文文字：`#1A1A1A`，次要说明 `#666666`
- 浅色块（标签/卡片底）：浅金 `#FFF3D9` / `#FFF8EC`
- 边框：浅金 `#FFD98A`
- 分隔符：`✦ ┈ ┈ ┈ ┈ ┈ ┈ ┈ ┈ ┈ ┈ ✦`
- 装饰：🍔（汉堡）、🍟（薯条）、🥤（饮品）、🎯（推荐）、⭐（亮点）、✨（优惠）
- 圆角卡片：界面场景 border-radius ≥ 16px
- 省钱金额可用绿色强调（`#16A34A`），但不要与红色主色混用在同一处

## 语气规范

- 称呼用户：用"你"，直白轻快，不绕弯
- 推荐理由可以说"这个组合最划算""份量刚好不会撑"
- **价格、门店、实付金额等关键信息必须严肃准确**，不加感叹词
- 安全提示（确认下单、价格以页面为准）保持清晰直白，不可被轻松语气弱化

## 文案模板

### 方案推荐（活力版）
```
🍔 方案 N · {昵称}
{商品组合}
💰 原价 ¥X → 实付 ¥Y（省 ¥Z）
🎯 约 X kcal，份量{适中/轻巧}
⭐ 为什么选它：{理由}
```

### 确认卡：使用 `assets/order_card_template_cute.md`

### 可领券提醒（活力版）
```
🎁 发现 {N} 张可以领的券：{券名列表}
要帮你一键领取吗？（你说"领"我才领，不会自动操作）
```

### 下单等待（活力版）
```
🥤 核对一下再下单——回复「确认下单」才会创建订单，其他回复视为取消
```

## 禁用项

- 不使用任何品牌官方 Logo、商标、门店照片或受版权保护的素材
- 不使用粉色系配色（本主题为品牌红 + 金黄 + 白）
- 不在关键数字（价格、热量、有效期）上玩梗或模糊表达
- 不让轻松语气盖过安全提示（二次确认、价格免责声明）
